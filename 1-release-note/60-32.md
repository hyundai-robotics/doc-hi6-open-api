    当请求来自外部源的轨迹时

- set_cur_pc_idx<br>
  - 添加验证以防止在程序播放时调用
- emergency_stop<br>
  - 调用时显示通知弹出窗口
- emergency_stop_test<br>
  - 修复请求立即停止（类别 0）时返回 403 BAD Request 的错误
  - 通过验证案例细化错误代码
  - 调用时显示通知弹出窗口
- execute_move<br>
  - 修复与响应相关的错误并细化错误代码
  - 添加验证以允许仅在远程模式下操作
- motor_on API<br>
  - 修复在远程模式下程序播放期间切换到手动模式后 motor_on 无法正常工作的问题  
  - 添加验证以允许仅在远程模式下操作
- start<br>
  - 修复在远程模式下无法调用的问题
  - 添加验证以允许仅在远程模式下操作
- stop<br>
  - 修复在远程模式下无法调用的问题
  - 调用时显示通知弹出窗口
- reset<br>
  - 修复在远程模式下无法正确操作的问题
- 修复在以下顺序调用 API 时程序执行多次的错误<br>
  - Motor On → R0 → 删除作业 → 上传作业 → 重新加载作业 → 设置当前 PC → 启动机器人
